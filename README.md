# Folio — AI Metadata Generator for Audio Storytelling

Folio is an AI-powered tool that helps audio storytellers generate high-quality metadata — titles, hooks, descriptions, and tags — directly from raw scripts.

Built with a focus on platforms like Pocket FM, where storytelling meets discoverability.

---

## 🚀 Problem

On storytelling platforms, creators don’t just write episodes — they also need to:

- craft engaging titles
- write compelling hooks
- define mood and tags
- structure cliffhangers

This process is:
- repetitive  
- cognitively heavy  
- inconsistent across creators  

As a result, great stories often struggle with discoverability.

---

## 💡 Solution

Folio transforms raw scripts into structured, platform-ready metadata using AI.

It acts as a **creator-side assistant**, reducing effort while improving consistency and quality.

---

## ⚙️ Features

- 🎯 Multiple title suggestions (short, platform-optimized)
- 🧠 Hook line generation (for retention & CTR)
- 📝 Description writing
- 🏷️ Tags and mood markers
- ⚠️ Content warnings
- 🎭 Tone control  
  (Dramatic, Dark, Emotional, Youthful)
- 🔁 Regenerate for variation
- 📋 Copy-ready outputs for fast publishing

---

## 🧠 Product Thinking

Folio is not just an AI wrapper — it is designed as a **workflow tool for creators**.

Key decisions:
- **Tone control** → simulates creative direction & experimentation  
- **Regeneration** → supports iteration before publishing  
- **Structured output** → aligns with platform metadata systems  
- **Copy-first UX** → optimized for real creator workflows  

The goal is to reduce friction between **writing** and **publishing**.
